# Joni Tracker

A calm, private log for newborn feeds, diapers, and postpartum meds. Everything stays on the phone.

## Play it

[https://dust2ash7.github.io/joni-tracker/](https://dust2ash7.github.io/joni-tracker/)

On iPhone, open that link in Safari, tap Share, then **Add to Home Screen**. The icon is the green leaf, and the name under it is Joni.

## Run it locally

```bash
npm install
npm run dev
```
